## 可扩充的来源

HLTV 的选手图库入口形如 [ZywOo 个人图库](https://www.hltv.org/galleries?player=11893)。此前已读取的索引包含多个赛季、个人照与队友合照；每个赛事相册有独立标题与照片页，照片页可标注人物 Player ID。适合按“选手 ID → 赛事相册 → 年份 → 照片页”逐级建立可追溯清单。

先检查赛事标题中的年份，再记录该照片页的明确人物标签；合照未逐脸确认的背景人物不自动补名。没有年份的赛事须另查官方日期，不能把访问日期、图片编号或侧栏比赛时间当作拍摄时间。摄影者字段没有保存到姓名时明确写明，不虚构作者。

已保存的 Commons 人物分类、ESL/Flickr 摄影记录可作为补充。原文件明确许可与摄影者随图保留。批量关键词搜索会出现 Fallen / frozen 风景、Oskar Holm / ins 与 Joshua Potter / INS、巴西 ZeusCSGO 与乌克兰 Zeus 等错误匹配，必须结合真实姓名、稳定 ID 与人工检查排除。

## 当前访问情况

本次新访问 HLTV 照片页显示 Cloudflare “Sorry, you have been blocked”；已知 CDN 原地址返回 403。停止了进一步网络采集，未绕过限制。本轮扩充使用此前已经下载的原片，未将待采集地址算成已收集照片。

`research/hltv-album-download-queue.json` 保存此前读到但尚未下载的照片元数据，包括来源页、赛事年份、明确人物标签和原始图片地址。它是候选队列，不是已发布素材。

```sh
npm run collect:album -- --dry-run
npm run collect:album -- --limit 20
```

工具仅下载已经记录的直接来源 URL，默认每批 20 张、间隔 2 秒、逐张落盘，可恢复进度；403/429 立即停止，连续三次网络错误停止，不绕过访问限制。下载到 research/album-downloads 后仍须身份、年份、版权和清晰度人工审核。网站构建不会联网采集，也不会把这些候选自动发布。

HLTV 使用状态按项目所有者此前声明记录；不标成平台官方授权或开放许可。完整逐图清单见《赛事相册清单.csv》《照片署名与许可.md》。
