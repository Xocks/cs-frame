排名固定为 2026-10-19，阵容于 2026-10-21 核对；不是自动变化的实时排名。

新增 HLTV 头像由稳定 Player ID 个人页的 canonical、昵称、真名和 og:image 映射，核对单一人脸并逐张检查联系表。不同年龄的历史素材按原始年份保留；头像采集日期不冒充拍摄日期。图库候选须只标注目标人物，进一步剔除多人、模糊、面部遮挡和近重复构图。8 位重点选手的个人图库已按较早、中间和近期年份检查，最后仅纳入通过清晰度筛选的 9 张。没有用同次拍摄伪装多个年龄。

照片数量与人物覆盖达标，**跨年龄素材仍不充分**：只有 7 人拥有两个已核实年龄时期。其余无可靠日期的照片继续显示“年龄未核实”，年份按钮便于浏览，不能宣称全部选手已有 2–3 个年龄阶段。

HLTV 素材按项目所有者的使用权限声明纳入，版权归原权利人，未写成已获得官方授权。Commons 照片保留公开许可。原片只裁切、缩放、转 WebP，没有生成或重塑人脸。

## 已完成的在线功能

浅深色、卡片和切图动画、减少动态效果、桌面与手机适配；队伍/排名/国籍/档案筛选、搜索、随机和盲评；大图、时期/年份及候选切换、代表照；整体与分时期独立评分；个人/战队/时期/中国/现役历史对比；IndexedDB、本地兼容存储、JSON 导入导出和 CSV。未评分不作为零分。

没有公共评分后端。每位朋友的数据保存在各自浏览器，不会冒充全站总榜。

## 测试证据

- 数据结构、稳定 ID、队籍、Top20、所有本地文件引用/格式/尺寸/哈希、年龄一致性检查通过。
- 7 项 Node 单元测试通过。
- 在线 Playwright Chromium 7 项通过、0 项失败；使用 /frame-cs/ 子路径模拟 GitHub Pages 项目路径。
- 逐一加载全部 622 个图片规格，无失败；页面没有访问 HLTV、GitHub Raw 或第三方字体/API 来运行。
- 整体和时期评分独立保存，刷新恢复，代表照恢复；JSON/CSV 下载、新浏览器上下文恢复和无效导入拒绝已验证。
- 盲评、搜索真名/ID、队伍/国籍/排名筛选、战队样本均分、手机390×844、桌面1440×1000、深色、焦点和 Escape 均已验证。

截图在 desktop.png、desktop-dark.png、mobile.png、mobile-detail.png；机器可读结果在 playwright-online-results.json。当前尚无国内三运营商实网测试，不能承诺全国访问稳定。
