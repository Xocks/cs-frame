# 准星之外 CS PORTRAITS · 在线版使用说明

当前开发重点为在线网站，单机版与离线打包暂停。旧离线文件保留为上一版，不包含本轮新增的 HLTV 素材。

打开已部署的网址即可使用，无需安装。网站脚本、字体和照片使用同站静态资源；点击来源链接时才访问原始网站。

## 浏览与评分

按昵称、HLTV ID、真实姓名或队伍搜索，组合队伍、排名、国籍和现役快照/历史标签筛选。默认仅显示有照片的人物，取消可查看所有档案。历史名将标签不代表已退役。

点击人像打开详情，切换时期及该时期的候选照片。“选为我的代表照”会更新卡片并记住时期首选。

- 整体评分：每人一份 1–5 分。
- 分时期评分：每人每个时期一份 1–5 分，不覆盖整体分数。
- 暂时跳过不会产生分数，未评分不作为零分。
- 盲评隐藏身份，关闭后揭晓；随机只改变顺序。
- 榜单包含个人、战队、时期、中国选手和现役/历史对比，队伍均分显示已评分样本数。

HLTV 个人资料页头像没有可靠拍摄日期时显示“档案头像”，归入“年份与头像”，不会把采集日期当成拍摄年份。已核实的其他年份照片可从时间轴切换。

## 完整赛事相册

从主导航进入“赛事相册”，可按年份、选手、HLTV/Commons、合照与个人现场筛选，点击图片查看保留完整构图的大图。支持左右箭头按键、Esc 关闭；来源详情包含年份依据。个人详情页也可以直达相关赛事相册。

## 保存与备份

评分保存在当前浏览器，优先 IndexedDB，并尝试 localStorage 兼容备份；没有后台上传，不会自动汇总朋友们的分数。更换浏览器、网站域名或清除浏览数据可能影响保存。

“备份”可导出 JSON / CSV。JSON 恢复两种评分和照片选择，合并时较新的评分优先，保留当前界面设置；无效文件整份拒绝。建议定期备份。

网站只预缓存页面和程序，照片在浏览时按需加载并缓存；看过的照片可离线再看，未浏览的照片仍需联网。离线交付本轮暂停，不承诺旧单机包包含新照片。

## 动画与手机

支持浅深色、卡片悬浮、照片过渡、弹层及评分反馈；系统“减少动态效果”设置会降低运动。详情可用 Tab 遍历、Esc 关闭。手机直接用浏览器访问网站。

## 照片来源

详情中的“照片来源与核验记录”显示原始页面、摄影者、版权状态和裁切记录。Commons 素材保留公开许可，HLTV 素材按项目所有者的使用权限声明纳入，未写成平台官方授权。图片只裁切、缩放、转格式，不生成或重塑五官。身份或图片无法确认的档案继续留白。
