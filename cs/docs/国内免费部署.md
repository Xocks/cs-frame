# 国内访问与免费部署

核查日期：2026-10-21。当前交付网站部署包，不自动创建或公开发布第三方站点。

建议采用腾讯 EdgeOne Pages 中国站的静态托管。本站无服务器、数据库、在线字体和远程图片依赖；评分保存在浏览器，不产生后端费用，也不会自动汇集不同朋友的分数。

## 免费能做到什么

官方 FAQ 当前说明有长期免费套餐，包含不限量网站加速流量和请求、平台基础防护，以及有配额的构建、函数和 KV。本站不使用函数或 KV，实际额度以你账号控制台显示为准。

来源：[EdgeOne Pages 常见问题](https://edgeone.cloud.tencent.com/pages/document/162936949996421120)。

## 国内顺利访问需要什么

长期面向中国大陆访问，优先选择中国大陆或全球含大陆加速区域，并绑定已经完成 ICP 备案的自定义域名。官方域名规则说明：含大陆区域的系统预览链接有效期 3 小时；不含大陆区域的默认项目/部署域名在大陆网络可能返回 401。因此不能把随手生成的免费临时链接作为长期国内访问地址。

来源：[Pages 域名与加速区域说明](https://edgeone.ai/document/175201428435140608)。

已有备案域名时，可以尝试做到托管和 HTTPS 零月费；没有域名和备案时，不能承诺“总成本永久为零且全国稳定访问”。域名注册与续费、办理备案所需的服务条件应由所选服务商核实。备案流程不等于购买本项目的后端服务器。

## 直接上传网站部署包

1. 登录 [腾讯云 EdgeOne Pages 控制台](https://console.cloud.tencent.com/edgeone/pages)。
2. 创建项目，选择直接上传；使用 `delivery/准星之外-网站部署包.zip`，或上传 `dist/` 内的全部文件。
3. 确认根目录直接含 `index.html`，而不是多包了一层目录。
4. 选择合适的加速区域，绑定已备案的自定义域名，并按控制台提示添加 DNS CNAME、启用 HTTPS。
5. 等待部署完成，用电信、联通、移动的实际大陆网络分别检查首页、图片和详情；本地测试不能代替这些实网检查。
6. 首次打开后等页脚出现“离线已就绪”；之后断网仍可打开已缓存版本。新用户首次访问仍需要联网。

官方支持直接上传 ZIP 或文件夹：[产品动态](https://edgeone.cloud.tencent.com/pages/document/162936998387830784)。

官方直接上传文档列出的资产限制为 1000 个文件、单文件 25 MB，最终以控制台为准。网站部署包将图片分开存放，避免内嵌单 HTML 超过单文件限制。后续图片增加到 500 张时，卡片与大图会超过 1000 个文件，应改用 Git 构建并检查平台文件数量限制，或合并部分规格。

来源：[直接上传](https://edgeone.ai/document/173731777484574720)。

## 从源码构建

```sh
cd cs
npm ci
npm run check:data
npm test
npm run build
```

构建命令 `npm run build`，输出目录 `dist`。在仓库根配置 CI 时，应用根目录指定 `cs`。可通过支持的 Git 平台部署，避免把 `node_modules` 或离线单文件上传为网站源码。

网站可以置于主域名根目录或 `/cs/` 子目录；构建采用相对资源路径。F1 内容未创建，也不会被本次 CS 工程覆盖。未来可在根站添加项目选择页。

## 后续多人汇总

当前每位朋友的数据互相独立，可各自导出 JSON/CSV。若以后要全站公共排行榜，需要明确账户、匿名标识、写入权限与防刷方案，再增加后端；当前页面不会冒充在线总榜。
